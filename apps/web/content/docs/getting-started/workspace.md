# Workspace & navigation

ResearchTrack opens into a **workspace** shell: a left app rail, a top header, and the main reading area.

## Left sidebar

Use **Projects**, **Teams**, and **Documentation** to switch scope. The branding block at the top returns you to the project list.

## Header

The header repeats quick links (Documentation menu, project/team shortcuts) and account controls. Documentation pages use a **Topics** column and, when a page has headings, **On this page** on the right.
