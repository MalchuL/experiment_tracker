# Projects

Projects group experiments, metrics, and settings for one research effort.

## Creating and opening

From **Projects** in the workspace, create a project or open an existing card. Inside a project, the sidebar switches to project sections: Overview, Experiments, Metrics, and more.

## Settings

Project owners and maintainers can adjust metadata and membership under **Settings** for that project.
