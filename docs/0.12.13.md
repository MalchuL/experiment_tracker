# 0.12.13

## Web UI

- **Create metric from scalar point modal.** Long experiment names now wrap inside the modal instead of overflowing horizontally, keeping the dialog usable for runs with very long names.
- **Scalars refresh controls.** The manual refresh action is now an icon-only button with no loading text; the icon spins only after the user presses it and stops when that manual refresh finishes. The auto-refresh progress circle moved to the far right of the Scalars page actions, after **Hide Settings** / **Show Settings**.
- **Scalars experiment list wrapping.** The Scalars experiments sidebar adds a **Wrap experiment names** toggle. When enabled, long experiment names wrap in the list instead of forcing horizontal scrolling.
