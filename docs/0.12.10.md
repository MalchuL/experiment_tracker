# 0.12.10

## Web UI

- **Compare Scalars hover name length.** Each compare scalar plot adds a **Hover name** slider in plot controls, matching the main Scalars page settings sidebar: default **50** characters, range **10–250**, step **5**. Tooltip experiment names truncate to the chosen limit via the same `buildExperimentHoverDisplayNames` logic used on the Scalars page. The value is stored per plot in compare scalar plot config (`localStorage`); older saved plots without the field load with the default.
- **Compare Metrics duplicate experiment names.** Metrics compare plots key the X-axis and vertical separator lines by experiment id instead of display name, so runs that share the same name still get separate columns and grid lines. Axis ticks and tooltips continue to show the plain experiment name.
